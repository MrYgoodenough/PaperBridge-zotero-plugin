## 核心实现

- 后端继续使用一个串行工作线程和独立引擎子进程；没有新服务、框架或依赖。取消受限时处理，父进程失联后引擎自行退出，不盲杀旧 PID。
- 质量记录观察固定引擎的真实段落应用、缓存、跳过、失败及回退；“完整”只表明结构/应用证据完整，不是语义认证。SDK 隐式重试关闭，失败后的自动回退只使用已确认缓存。
- 前端提交前保存归属；响应丢失时按指纹或重试关系恢复，不自动重发。后端已接受重试但索引写入失败时继续跟踪；取消写入失败不会遗留源任务锁。
- 重试保留旧成果；未导入旧结果退出自动保存路径。导入 key 与 record/job 关系用于恢复元数据/索引失败。
- 默认 DeepSeek 保留，兼容配置独立管理 HTTPS 端点、模型、JSON 模式与 token 上限；不发送默认 DeepSeek 思考参数。密钥只留登录管理器及运行中的请求，不写任务清单或缓存键。

维护入口见 `docs/tasks-and-results.md`；已维护 `MEMORY.md`，移除过时的永久删除规则和失效风险描述。
