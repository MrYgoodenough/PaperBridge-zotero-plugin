## 直接修复

- **字形与映射**：修复 fi/fl/Th/ffi 等复合 ToUnicode 及虚拟 metric tail 的真实 paint 证据；保留可见空格完整 raw bounds。没有通过模糊文本匹配或放松后端可信几何伪造覆盖率。
- **空白样式缓存**：纯空白 rich-style 不再制造不可满足的样式约束；仅迁移原已有效的空白变换，保留公式及真实样式，避免不必要的重复收费。
- **出版/作者信息**：开篇短姓名、位置及机构证据取代宽泛 bold 判定，Science/Wheat 正文不再误作作者排除；保留无 bold 的 Elsevier 作者及 IEEE 混合作者机构块。完整短 DOI/Received/revised/Accepted 源块恢复，不再裁切日期。
- **保护区与参考文献**：识别 STAR+METHODS 等参考文献结束边界；修复相交保护框合并成整页的 L 形回退，v8 仅合并包含或同列紧邻源裁切区。Elsevier-05 第 8 页中文致谢/补充材料恢复，原 paid-final 的 86 个 verified source footprints 全保留；第 1 页日期/legal 局部 2× 像素差异为 0。
- **窄范围语义保护**：发现明确 1D/2D/3D 标签变义，增加返回及缓存校验；拒绝错误标签而不冒充一般科学语义认证。
- **原生 GUI 功能**：在任务窗口直接绑定 opener 的 Zotero 实例，修复“打开译文”错误；hover 仅补偿横排原生 Range 上下字体留白，中心及至少 60% 高度仍须属于同一可信行，横向/旋转/倾斜边界保持严格。
