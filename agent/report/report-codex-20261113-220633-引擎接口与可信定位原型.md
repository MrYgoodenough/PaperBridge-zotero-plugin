## 关键实现

- `backend/alignment.py`：Schema 1，PDF user space / 0-based page / 双方 SHA-256。同单元捕获且已应用才作为候选，核对最终可见字面文本/几何，不做双语语义猜配。邻接 glyph 的字体度量框重叠不误判为遮挡；非文本覆盖仍保守排除。
- `addon/content/alignment.js` 与父级集成：passive capture 只记普通点击位置，独立按钮才导航；各侧用自己的 viewport；关闭、缩放、旋转、重渲染清理事件/临时 DOM。直接修复 Gecko 跨 compartment 数组及 DOM wrapper identity 问题。
- 分隔条直接修复 XUL `flex` 整数属性，真实 trusted 拖动后宽度变化已验收，关闭恢复原属性/样式；没有另起布局实现绕过失效对象。
- `library.js` 保存 sidecar 路径，新重试清空旧映射；后端校验只读，不提交任务。研究、配置与维护入口见 `docs/engine-and-alignment.md`。
