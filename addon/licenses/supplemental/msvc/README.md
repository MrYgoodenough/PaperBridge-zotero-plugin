# Microsoft runtime terms

The original Microsoft Runtime 2015–2022 and Visual Studio Community 2022
license documents and VS2022 REDIST page are retained unchanged. Their official
URLs, byte counts and SHA256 are in `../public-source-evidence.json`.

The Runtime license permits installation/use, not sharing or distribution to
others. The separate Visual Studio license and REDIST list permit conditional
distribution of listed unmodified files with a program by appropriately licensed
users, with distribution requirements/restrictions. The Community terms are an
identified public grant route, not a claim that this distributor holds that license.

The observed DLL versions are 14.44.35211.0 and 14.40.33810.0. Their precise
release origin and this distributor's license basis remain unconfirmed. Neither
version/copyright attribution nor retaining these documents resolves that
question. Microsoft DLL source is not substituted for, or demanded by, this grant.
