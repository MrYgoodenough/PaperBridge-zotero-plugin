# PaperBridge 0.4.2

安装包：`dist/paperbridge-0.4.2-macos-arm64.xpi`。macOS Apple Silicon，自带 Python、排版依赖及模型；保留 Zotero 9–10 的兼容声明。

## 公式复制

- **长公式**：鼠标移入独立公式区域，出现复制图标；点击复制为 `$$…$$`。
- **短公式**：保留选中文本后在弹窗或右键菜单复制为 `$…$` 的方式，也可手动选择 `$$…$$`。
- 长公式区域使用安装包已有的排版模型在本地识别。悬停和区域识别不调用 DeepSeek，不上传整篇 PDF。
- 点击复制时优先使用本地缓存或 Zotero 已有 LaTeX，未命中才将选中公式及其字形坐标发送给已配置的 DeepSeek。
- 普通 PDF 的结果仍是模型转写；无可选文本的扫描公式不提供图像 OCR。0.4.1 之后没有更改转写模型或提示词。

## 每篇 PDF 一个持久 JSON

位置为 **Zotero 数据目录 / paperbridge / formula-cache / `<原 PDF SHA-256>.json`**。目录不在版本化引擎中，升级不会移除。

每个 JSON 包含公式的 LaTeX 结果、已识别页面的长公式区域、文献库/论文/关联附件引用。原文和关联译文共用原 PDF 的缓存；相同内容的 PDF 可由多个论文条目引用。行内与独立公式只改变复制时的分隔符，不重复转换。同一选区的并发复制合并为一次请求。

缓存使用原子写入，文件权限为 0600，不保存 API Key。查看缓存无需启动翻译引擎或发送 API 请求。

| 操作 | 行为 |
| --- | --- |
| 关闭阅读器、重启、升级插件 | 保留 JSON 与已识别的页面区域 |
| 只删除原 PDF，论文条目仍在 | 保留缓存，关联译文继续使用 |
| 删除一个译文附件 | 仍有论文或其他关联附件引用时保留 |
| 删除论文条目或移入回收站 | 移除该论文引用；无其他引用时删除 JSON |
| 插件停用期间删除论文 | 下次启动重新核对引用并清理 |
| 删除独立 PDF，且没有所属论文或其他引用 | 清理其 JSON |
| 手动清除公式缓存 | 只删除公式结果与公式区域，不修改 PDF、标注、笔记或全文翻译缓存 |

论文条目本身仍存续时，即使原 PDF 附件已删除，也视为有效引用。共享同一 PDF 内容的另一篇论文仍存在时，只移除被删除论文的引用，保留其他论文使用的缓存。恢复论文不会恢复已经清理的公式缓存。

## 查看与清除

打开 **工具 → PaperBridge → 公式缓存…**，或在设置窗口点击 **公式缓存**。

左侧选择 PDF，右侧查看公式文本、LaTeX、已识别页数、引用数及 JSON 文件名。支持清除所选 PDF 或全部公式缓存。缓存损坏时会在列表中提示，可手动清除后重新生成。正在转换时手动清除，旧响应不会把清除的缓存重新写回。

## 验证

过程文件、测试配置及隔离文献库保存在工程 `.runtime/`，运行时构建材料位于 `.cache/package/`。测试不操作日常文献库。

- `tests/test_formula_cache.cjs`：每篇 PDF 一个 JSON、附件共享、重载后无 Key 命中、并发去重、删除规则、损坏缓存及清除时的并发请求。
- `tests/test_formula_regions.py`：独立公式提取、正文隔离、0/90/180/270 度旋转页面及无效输入。
- `tests/zotero_042.js`：在实际 XPI 内验证悬停图标、点击复制、持久缓存窗口和真实 Zotero 条目/附件删除。
- `tests/zotero_10.js`：继承 0.4.1 的标注持久化、分屏、公式入口及停用清理回归。

公式转写接口用可计数的模拟响应验证请求次数和缓存行为；本地长公式识别使用实际内置模型。本轮不新增付费 DeepSeek 转写请求，不将模拟响应当作真实识别准确率验证。
