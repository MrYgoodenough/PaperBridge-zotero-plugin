# PaperBridge 0.4.1

以下为维护者独立 macOS 0.4.1 包的历史说明。PR #3 的共享源码合流不重新发布或覆盖此包，也不把当时的验收扩展到三平台合流包。

## 安装

安装包：`dist/paperbridge-0.4.1-macos-arm64.xpi`，自带 Python、依赖和排版模型，适用于 macOS Apple Silicon。
在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」选择此文件，可覆盖旧版。

兼容声明为 Zotero **9.0–10.***，包含整个 10 主版本。当前实际测试版本为 **10.0.9**；未来尚未发布的 10.x 无法逐一实测。
开发接口核对依据：[Zotero 10 官方迁移说明](https://www.zotero.org/support/dev/zotero_10_for_developers)。

## 译文标注

- 右侧使用与译文附件关联的 Zotero 原生阅读器，支持高亮、下划线、笔记注释、文字、区域及绘图工具。
- 标注保存到译文 PDF 附件的 Zotero 标注数据中，关闭分屏、重开分屏或单独打开译文附件后可继续编辑。
- 编辑权限遵循附件所属文献库权限；只读文献库仍为只读。
- 狭窄分屏中的标注工具放在工具栏第二行，保留页码、搜索和缩放功能。
- 关闭分屏前会保存尚未写入的编辑，原文和译文的标注各自独立。

双向翻页、滚动及缩放同步保留。**两侧标注自动对应后置**：译文段落重排后，直接复制原坐标不能保证对应同一段文字，本版不自动复制标注到另一侧。

## 公式复制

在译文中选中完整公式，选区弹窗选择「复制公式 $…$」或「复制公式 $$…$$」，也可使用右键菜单：

- 行内公式：`$x_i^2$`
- 独立公式：`$$\sum_{i=1}^{n} x_i$$`

原文及单独打开的译文附件也可使用。普通复制操作保持 Zotero 的行为。

Zotero 已提供 LaTeX 的数学对象直接复制，无 API 请求。普通 PDF 选区使用设置中的 DeepSeek API Key，通过 `deepseek-flash` 转写为 LaTeX；只发送所选文本和选区中字形的位置，不上传整篇 PDF。第一次转换可能需要等待，并产生相应 API 用量；同一附件、同一选区的结果在本次插件会话中复用，最多缓存 100 条，不写入磁盘。

原 PDF 通常不包含原始 TeX 源码，因此普通 PDF 选区得到的是模型转写，复杂公式需核对；无可选文本的扫描公式未提供图像识别。转换失败时保留剪贴板原内容，不用猜测结果替换。

## 验证与过程文件

- 运行时、测试配置、隔离文献库和控制台日志位于工程 `.cache/package/`、`.runtime/zotero10-*`。
- `tests/test_formulas.py` / `tests/test_formulas.cjs`：分隔符、结构校验、选区范围、字形坐标、会话缓存与复制失败保护。
- `tests/zotero_10.js`：完整 XPI 在 Zotero 10.0.9 中验证引擎、译文附件标注保存/重开/删除、关闭分屏与标签页、双向翻页、公式复制入口和剪贴板。
- `tests/formulas_provider.py`：可选的真实模型烟雾测试。此次项目 `.env` 测试密钥返回 HTTP 401，未完成真实模型识别准确率验证；不将模拟响应当成真实识别结果。

2026-11-12 打包时未提交源码。

验证结果：后端 **53 项**、Zotero 10.0.9 集成 **30 项**通过；JavaScript 同步与公式剪贴板检查通过。完整记录见 [verification-0.4.1.json](verification-0.4.1.json)。集成测试使用公开论文的两个独立附件副本，验证原生阅读器和标注归属，本轮未执行付费全文翻译。安装包 **173.02 MiB**，ZIP 完整性与源码一致性校验通过。
