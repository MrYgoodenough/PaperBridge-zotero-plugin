# 0.3.6 后续工作建议

共享源码为 **0.3.6 候选**；四条 Linux/Windows 稳定通道仍为 **0.3.4**。按个人实用产品安排，不增加企业级治理、冗余框架或引擎迁移。

## 本轮交付边界

- P0-3：最简 NOTICE 与 CPython/native/model/tokenizer 来源证据已绑定实际版本/hash；**完整法律合规仍 unknown**。
- P1-5：隔离原生删除/回收站/恢复、共享归属、真实缓存清理和真进程冷重开；清理不取消任务，结果/映射/未知身份不猜删。
- P1-6：Linux 只达到既有 macOS 的 OpenCV `core/imgproc/imgcodecs/python3` 范围，每种包同源码对照约省 **55.25 MiB**；不引入 XZ、别名恢复、模型删减或进一步 strip。
- 可信映射为独立、版本化 Zotero imported JSON 附件；阅读重算双方 PDF hash、核对 exact keys/parent 和真实页界，不需 Python/API。几何变为逐行 quads，保留行间/短末行空白，schema 1 兼容。
- 原生隔离文件下载不等于真实账号云 metadata 同步；缓存重排/结构 verified 不等于人类双语接受。公开新版本和稳定 feed 仍须另获发布授权。
- P0-1 已准备原始许可与 303 个固定源码归档，四包源码字节交付已核；法律与实际公开交付义务仍未闭环。用户已确认 Community 2026 第 8 条分发责任，微软 DLL 专属条款及当前四包的原生同意/豁免、health/冷重开已核，见 [条款范围](runtime-terms-acceptance-0.3.6.json)。P1-3 的 Windows 150% 升级/notes/诊断证据冻结在 MSVC 整合前 hash，100% 旧包证据及未测物理错误边界见 [验收范围](windows-acceptance-0.3.6.md)。真实账号仍未完成，文件同步保持关闭。

## 暂不推进

- BabelDOC 固定 **0.6.4** / PyMuPDF **1.26.7**；新版迁移低优先级，**不列为 TODO**。
- macOS 专属源码未取得，不合流、不反向提取、不重建覆盖已有 0.4.2 发布物。
- Linux 已达到用户要求的同 macOS 修剪程度，暂不进一步精简；不再列 XZ/strip/别名恢复为下一步。
- 任意段落局部重译/增量排版、精确原译批注同步仍是高成本研究，不能用选页新任务或猜坐标复制冒充完成。
