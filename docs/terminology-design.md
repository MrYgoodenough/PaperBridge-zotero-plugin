# 术语与自定义规则：保留设计

这是尚未交付的独立扩展设计，不代表当前术语表功能，也不提高 BabelDOC 新版迁移优先级。当前仍以固定 0.6.4 下可用的翻译/保护/缓存/阅读为基线。

## 最小接入方式

- 在设置中单独管理少量 source → target 术语和简短规则，按全局/语言/服务作用域明确选择。
- `tasks.js` 在入队时冻结规范化规则；`deepseek.py` 将有界规则加入当前请求，不另起翻译实现。
- `library_cache.py` 将稳定规则内容/版本纳入段落与整篇身份。改规则不复用错误旧译文，不删除已保存成果。
- 不替换受保护公式、代码或出版信息，不用字符串后处理静默篡改 PDF。

相同源术语的冲突必须可见；空项忽略、长度控制适当，不让非致命规则错误关闭基本翻译。自定义内容作为用户配置，不是系统指令或文档中的潜在指令。将新增提示 token 纳入真实用量，兼容服务不假定额外能力。

## 修改与验证入口

设置 `settings.*` / `prefs.js`；任务快照 `tasks.js` / `library.js`；请求 `deepseek.py`；身份 `library_cache.py`。先实现小型显式术语表，再按实际需要加入自定义规则，避免复杂模板/作用域/自动发现系统。

只为配置冻结、冲突、缓存隔离和公式不变增加必要测试；真实论文术语准确性仍需双语复核。正式实现时更新相应使用说明，不在 MEMORY/TODO 中堆叠未执行计划。
