# 0.3.5 之后：实用产品路线

## 当前判断

已经不需要重做任务调度、批量入口、附件保存、恢复记录、页同步或悬停。这些基础能力有明确实现和早期 Linux/Windows 验收。本轮 0.3.5 修了密钥替换、资源错误和书目/字体问题，新增启动失败诊断、一次性服务检查、双向显式定位与独立笔记链路，并补候选构建和实际包清单。

**剩余瓶颈是“当前包在用户平台真正稳定、译文能信任、发版可控”，不是功能数量。** 0.3.5 仍为候选：Windows 本轮未验收，公开稳定通道保持 0.3.4；macOS 独立产物不合流、不覆盖。质量结构账本 complete 不是人类接受，真实云兼容服务也没有偷偷增加付费验证。

估算为单人工作日，适用个人内部产品，不含等待设备/人工审查/用户授权；不是工期承诺。风险高时先做小范围验证，不另建庞大框架或苛刻门禁。

## 本轮有意不推进的方向

- BabelDOC 固定 **0.6.4**，新版迁移低优先级，**不列为 TODO 或当前优先事项**。不能用迁移替代直接修现有保护/字体/缓存问题。
- macOS 对应源码暂不可得，保持已有发布物和共享代码兼容；不合流、不验收、不反向提取源码。
- 繁体/日文保留切换接口，完整离线字体与语言支持延期；当前下拉框存在不等于已支持。
- 局部强制重译、增量排版和双向批注同步继续独立待办，不把选页重译、悬停或单向 note 汇总冒充它们。
- 不为“企业生产治理”增设庞大数据库、复杂多级发布基础设施、冗余回归门限；核心数据保存、费用确认和兼容路径保留必要保护即可。
